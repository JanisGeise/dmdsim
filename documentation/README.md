# dmdsim — Internal Documentation

Internal documentation of the `dmdsim` project, written for the developer to keep
track of what is happening inside the codebase. It is **updated with every new
implementation step**: `modules.md` and `architecture.md` are revised whenever
modules change, and every step appends a dated entry to `steps.md`.

- `architecture.md` — big picture: layers, data flow, the playground math, and the
  key design decisions (including their rationale)
- `modules.md` — module-by-module reference: what each file contains, its public
  API, and its conventions
- `steps.md` — chronological log of the implementation steps with what was built
  and why

Complementary documents in the repository root: `PLAN.md` (roadmap and milestone
status), `README.md` (setup, usage, running the GUI), and `run/reports/` (code
review findings per session, untracked).
